# Hi, I'm Jed 👋

I build **[Designs/OS](https://designs-os.com)**: open-source tools for architects,
BIM managers and the people who write software for them. Designs/OS is part of
AnJ Arch-Tech. No outside funding, just practical tools built in the open.

### Revit add-ins
- **[rst-c](https://rst-c.designs-os.com/)**: curated ribbon profiles for Revit
- **[Gantt-It](https://gantt-it.designs-os.com/)**: Gantt charts drawn inside your Revit project
- **[Splash-It](https://splash-it.designs-os.com/)**: color view tabs by file
- **[Pick-It](https://pick-it.designs-os.com/)**: pick a color and see its RGB values
- **[Drive It](https://drive-it.designs-os.com/)**: an MCP server that connects AI clients to Revit (early alpha)

### Dev tools
- **[Subfloor](https://subfloor.designs-os.com)**: a forkable shell substrate for a single code repository
- **[FAI Browser](https://fai-browser.designs-os.com/)**: a safer browser for coding agents
- **[md-converter](https://md-converter.designs-os.com)**: themed Markdown to styled, shareable HTML
- **[AnJ Cloud](https://anj-cloud.designs-os.com/)**: household file sync with a self-hosted gateway
- **[Storybench](https://github.com/jedbjorn/storybench)**: a local workspace for developing videos with an AI production agent
- **[Live Scenes](https://plasma-live-wallpapers.designs-os.com/)**: looping live wallpapers for KDE Plasma 6, Android and macOS
